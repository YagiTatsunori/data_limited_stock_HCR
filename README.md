# Contrasting performance of institutionally distinct empirical harvest control rules under identical operating models

This repository contains the R code and input data used in:

> **Yagi T. and Ichinokawa M. (2026)**\
> *Contrasting performance of institutionally distinct empirical harvest control rules under identical operating models*\
> ICES Journal of Marine Science.

Repository:

[contrasting_empirical_HCR](https://github.com/YagiTatsunori/contrasting_empirical_HCR)

## Introduction

Empirical harvest control rules (HCRs) are widely used for fisheries where conventional stock assessments cannot be conducted because of limited data availability. Different empirical HCRs have been developed independently by management organisations and research groups, often under different assumptions, management objectives, and operating-model structures.

This repository contains the code used to compare institutionally distinct empirical HCRs under an identical age-structured management strategy evaluation (MSE) framework. The analyses compare:

- the ICES rfb rule;
- the ICES chr rule;
- the Japanese type-2 rule;
- two modified HCRs generated by exchanging structural components between the rfb rule and the type-2 rule.

The study evaluates:

- management performance of alternative HCRs;
- robustness to fishing-history assumptions;
- robustness to species life-history characteristics;
- optimal tuning parameters estimated using a genetic algorithm (GA).

All simulations were conducted using a common age-structured operating model based on the framework developed by Fischer et al. (2020, 2022).

------------------------------------------------------------------------

## Simulation settings

### Stocks

The analyses evaluate four representative stocks spanning a broad range of life-history characteristics:

- Pollack (*Pollachius pollachius*)
- Thornback ray (*Raja clavata*)
- European plaice (*Pleuronectes platessa*)
- Anchovy (*Engraulis encrasicolus*)

### Fishing-history scenarios

The simulations include:

- one-way scenario;
- roller-coaster scenario;
- nine linear-change scenarios.

A total of **11 fishing-history scenarios** were evaluated.

### Harvest control rules

The following five HCRs were compared:

- rfb rule
- type-2 rule
- chr rule
- rfb rule with C̄
- type-2 rule with *f*

## Repository structure

### Main scripts

| File | Description |
|----|----|
| `functions.R` | Functions used throughout the analyses |
| `default_simulations.R` | Main MSE simulations using default parameter settings |
| `all_ga_do.R` | Genetic-algorithm optimisation of tuning parameters |
| `Fig1.R`–`Fig8.R` | Scripts used to generate manuscript figures |

### Data files

| File           | Description                                             |
|----------------|---------------------------------------------------------|
| `stocks.csv`   | Life-history parameters of the four study species       |
| `brps_new.rds` | Reference-point data (`Fcrash`) used in the simulations |

### Additional directories

| Directory               | Description                               |
|-------------------------|-------------------------------------------|
| `sensitivity_analysis/` | Scripts used for all sensitivity analyses |

------------------------------------------------------------------------

## Reproducing the analyses

The recommended execution order is:

1.  Run `default_simulations.R`
2.  Run scripts in `sensitivity_analysis/`
3.  Run `all_ga_do.R`

The scripts automatically generate the output files used in the manuscript and supplementary materials.
